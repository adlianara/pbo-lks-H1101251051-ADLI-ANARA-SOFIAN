## Deskripsi Proyek
Proyek ini merupakan hasil praktikum Pemrograman Berorientasi Objek (PBO), yaitu membangun REST API Perpustakaan menggunakan PHP, MySQL, konsep OOP, SOLID, PSR-4, dan arsitektur MVC.

## Fitur
- REST API untuk data buku (CRUD).
- REST API untuk data kategori (CRUD).
- Validasi input dan penanganan error.
- Database MySQL.
- Dependency Injection menggunakan Container.
- Frontend Dashboard.
- Manajemen Buku.
- Manajemen Kategori.
- Integrasi frontend dan backend.

## Teknologi
- PHP 8.2
- MySQL / MariaDB
- JavaScript
- HTML dan CSS
- Tailwind CSS
- Composer
- Git dan GitHub

## Cara Menjalankan

### 1. Backend
Masuk ke folder backend:

```bash
cd rest-api-perpustakaan
php -S localhost:8000 -t public
```

### 2. Frontend
Buka terminal baru:

```bash
cd frontend-perpustakaan
php -S localhost:3000
```

Buka browser:
http://localhost:3000
